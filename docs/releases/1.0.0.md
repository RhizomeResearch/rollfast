# Rollfast 1.0.0

Rollfast 1.0.0 is the first release with a stable public software contract. It
keeps the project research-oriented: optimizer profiles can remain
scientifically experimental while their Python API, Optax behavior, defaults,
and checkpoint schema follow the v1 compatibility policy.

## Highlights

- A broad Optax-compatible optimizer surface, including structured matrix,
  schedule-free, low-precision, and geometry-aware transformations.
- Plan-aware fine-tuning with grouped policies, EMA/SWA, SAM/ASAM, AdaLoRA,
  state migration, serialization, and diagnostics.
- JIT, mixed-precision, complex-policy, PyTree, optional-integration, and
  partition-aware test coverage.
- Build and minimal-import checks for the base installation without optional
  model libraries.

## Compatibility

The stable boundary and deprecation rules are documented in
[`../stability.md`](../stability.md). Users upgrading from 0.x should follow
[`../migrating-to-1.0.md`](../migrating-to-1.0.md), especially for optimizer
state and Schedule-Free evaluation parameters.

## Validation Scope

Release gates cover formatting, lint, typing, minimum and current dependency
tests, multiple forced CPU devices, examples, benchmark smoke scripts, source
and wheel builds, and installation from the built wheel.

GPU-specific behavior and publishable performance are not certified by these
gates. Validate kernels, sharding, memory use, and convergence on the target
accelerator and workload before production training.

## Known Scientific Limitations

Optimizer reports intentionally disclose profiles that are not reference
validated or that have known deviations from a paper implementation. Those
warnings remain part of the supported API and should inform workload-specific
evaluation; a stable version number is not a claim of universal optimizer
quality.
